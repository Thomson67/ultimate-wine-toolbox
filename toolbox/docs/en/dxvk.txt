DXVK / VKD3D-PROTON: CHOOSE GRAPHICS COMPONENTS

DXVK translates DirectX 9/10/11 calls to Vulkan. VKD3D-Proton performs this role for DirectX 12. They replace neither the Wine/Proton runner nor the graphics driver.

CHOOSE A BUNDLE
In Graphics settings, open the DXVK / VKD3D manager. A bundle groups the selected component versions. Select it globally or for one game, which keeps its own choice.

Start with Batocera’s included components. If a game has issues, try a Batocera model or a suitable bundle. Available models reproduce the component combinations of Batocera 40 through 43/43.1; they do not change your system version.

COMPATIBILITY
The newest bundle is not necessarily the best choice. Older runners may fail with recent VKD3D-Proton versions. Change one component at a time and keep a known working combination to make troubleshooting easier.

DXVK-NVAPI provides an NVIDIA interface used by some games. Its usefulness and available features also depend on the GPU, driver and DXVK/VKD3D versions. Adding NVAPI does not guarantee all NVIDIA features are available.

TEST OR ROLL BACK
Close the game, apply the selection and relaunch the same scene. If it crashes or regresses, restore Batocera’s default components for that game or choose an older bundle. Changing a bundle does not by itself fix a wrong executable, missing Windows components or incorrect game configuration.
