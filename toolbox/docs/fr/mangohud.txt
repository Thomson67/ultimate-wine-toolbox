MANGOHUD : AFFICHER LES PERFORMANCES

MangoHud affiche des informations pendant le jeu : FPS et, selon le profil, fluidité, charge, températures et mémoire. Il sert à observer les performances ; l’activer ne constitue pas une optimisation du jeu.

UTILISATION
Ouvrir Réglages graphiques, puis le menu MangoHud. Choisir l’activation globale ou un réglage propre à un jeu. Un jeu peut hériter du réglage global, être forcé sur Activé ou être forcé sur Désactivé.

Choisir un profil :
- Minimaliste : uniquement les FPS.
- Par défaut : affichage standard.
- Détaillé : FPS, fluidité, charge et températures CPU/GPU, RAM et VRAM.

Fermer puis relancer le jeu après un changement. Le réglage de la Toolbox concerne les jeux Windows qu’elle gère ; il ne règle pas l’affichage des performances de tous les émulateurs.

COMMENT COMPARER ?
Utiliser la même scène, la même résolution et les mêmes options graphiques. Observer la régularité, pas seulement le FPS maximal. Modifier un réglage à la fois permet de savoir ce qui améliore réellement le résultat.

SI L’AFFICHAGE MANQUE
Vérifier le réglage individuel : Désactivé peut prendre le dessus sur l’activation globale. Contrôler aussi les réglages déjà présents dans l’autorun et le comportement du runner. Consulter les logs de la Toolbox avant de modifier manuellement les variables.

Après une mise à jour du jeu, une ancienne bottle peut conserver d’anciens réglages. Le workflow de mise à jour WSquashFS nettoie celles du jeu après réussite. Une suppression manuelle de bottle peut également supprimer des données utilisateur : sauvegarder ce qui est important avant cette opération.
