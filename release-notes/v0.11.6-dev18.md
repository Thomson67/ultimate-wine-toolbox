## Français

Le menu **Paramètres → Options EmulationStation** de la Toolbox propose deux cases distinctes pour afficher les presets ReShade communautaires et les profils AntiMicroX communautaires. Les cases reprennent les options déjà affichées dans ES.

## English

The Toolbox **Settings → EmulationStation options** menu provides separate checkboxes for displaying community ReShade presets and community AntiMicroX profiles. Each checkbox reflects the currently exposed ES option.
