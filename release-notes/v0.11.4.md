## Français

- **Mise à jour des WSquashFS**. Les liens de sauvegarde existants conservent leurs destinations et leur écriture, y compris les liens relatifs. Les chemins des anciens `start.bat` sont conservés. Les règles `SAVEDIR` et `SAVEFILES` utilisent également les destinations permanentes pendant les essais.
- Une copie de sécurité séparée est créée avant le premier test. Le jeu utilise ensuite ses sauvegardes actives. Après une mise à jour réussie, la Toolbox propose de conserver ou supprimer les copies de cette opération.
- Les liens natifs créés pendant le test sont rétablis dans le préfixe de travail après une interruption de compression, un échec ou un refus de validation. Les chemins natifs sont préparés pour l’archive finale.
- Une relance après le choix d’un nouvel emplacement retrouve la progression préparée. Les alias internes des profils Wine et les préfixes renommés avec la compatibilité expérimentale Batocera 41 sont pris en charge.
- Correction du plantage `metadata : variable sans liaison` lors d’une relance en mode création.
- Pour une ancienne opération interrompue, `wsquashfs_update.py recover-original-saves <manifeste>` peut rétablir les destinations enregistrées. La progression du dossier temporaire reste disponible séparément pour récupération.

## English

- **WSquashFS updates**. Existing save links retain their exact destinations, including relative links. Paths in original `start.bat` files are preserved. `SAVEDIR` and `SAVEFILES` rules also use permanent destinations during testing.
- A separate safety backup is created before the first test. The game then uses its active saves. After a successful update, the Toolbox offers to keep or delete copies created by that operation.
- Native links created during testing are restored in the working prefix after compression interruption, failure or validation rejection. Native paths are prepared for the final archive.
- Relaunching after choosing a new save location retains prepared progression. Internal Wine profile aliases and renamed prefixes using experimental Batocera 41 compatibility are supported.
- Fixed the `metadata: unbound variable` crash when retrying a creation session.
- For an older interrupted operation, `wsquashfs_update.py recover-original-saves <manifest>` can restore recorded destinations. Progress from the temporary directory remains separately available for recovery.
