# Ultimate Wine Toolbox v0.9.0

## Français

Réglages MangoHud avancés et prise en charge expérimentale de ReShade en Vulkan sous Wine.

- **MangoHud** : réglages globaux et exceptions par jeu pour la VSync Vulkan (Mailbox, FIFO, Immediate ou adaptative), la VSync OpenGL et le profil d’affichage. Le mode Masqué conserve les réglages sans statistiques visibles ; le profil Détaillé affiche le mode de présentation Vulkan.
- **Limiteur MangoHud facultatif** : plafonds prédéfinis ou personnalisés, notamment au-delà de 60 FPS, et choix Early/Late. Aucun plafond ni mode de synchronisation n’est imposé par défaut. Désactiver le limiteur Batocera du jeu lorsqu’on choisit celui de MangoHud ; un plafond ne débloque pas un jeu limité en interne.
- **ReShade Vulkan sous Wine** : nouvelle API dans le parcours ReShade existant, avec les mêmes packs de shaders, presets et interface en jeu. Le chargeur Windows officiel VulkanRT 1.4.341.0 est téléchargé depuis LunarG et vérifié par SHA-256. La couche est enregistrée dans le seul préfixe du jeu, avec sauvegarde/restauration des fichiers et retrait ciblé de sa valeur de registre.
- Les réglages MangoHud, profils et presets existants sont conservés pendant la mise à jour. Les marqueurs des deux installateurs de test 0.8.1 sont archivés après installation réussie : leurs anciens retours arrière ne peuvent plus retirer les fonctionnalités intégrées à la version stable. Les sauvegardes des tests restent conservées.

**Validation utilisateur** : Azahar Windows sous Wine en Vulkan sur une configuration AMD ; ouverture de ReShade, création d’un preset et coexistence avec MangoHud/Mailbox sans problème signalé. L’utilisateur constate moins de latence avec Mailbox qu’avec la VSync interne d’Azahar. Ce retour ne valide pas tous les GPU, runners ou effets ; ReShade Vulkan conserve son libellé expérimental.

Validation automatisée locale : 911 tests, aucun échec, 7 ignorés faute d’outils disponibles. Vérifications supplémentaires des DLL officielles VulkanRT 32/64 bits, de l’installation depuis 0.8.1 avec et sans le test MangoHud, de la réinstallation et de la restauration hors ligne avec préservation des presets et réglages MangoHud.

Fermer les jeux et la Toolbox avant la mise à jour. Les deux fonctionnalités sont désormais accessibles directement depuis **Outils et compatibilité** ; les installateurs de test ne sont plus nécessaires.

## English

Advanced MangoHud controls and experimental Vulkan ReShade support under Wine.

- **MangoHud**: global and per-game Vulkan VSync controls (Mailbox, FIFO, Immediate or adaptive), OpenGL VSync and display profiles. Hidden keeps controls active without visible statistics; Detailed shows the Vulkan presentation mode.
- **Optional MangoHud limiter**: preset or custom caps, including above 60 FPS, plus Early/Late selection. No cap or synchronization mode is forced by default. Disable the game’s Batocera limiter when choosing MangoHud’s; a cap does not unlock an internally limited game.
- **Vulkan ReShade under Wine**: a new API in the existing ReShade workflow, retaining shader packs, presets and the in-game interface. The official Windows VulkanRT 1.4.341.0 loader is downloaded from LunarG and SHA-256 verified. Its layer is registered only in the game prefix, with file backups/restoration and scoped registry-value cleanup.
- Existing MangoHud settings, profiles and presets survive the upgrade. Markers from both scoped 0.8.1 test installers are archived after successful installation, preventing their old rollback commands from undoing the integrated stable features. Test backups are retained.

**User validation**: Windows Azahar under Wine using Vulkan on an AMD configuration; ReShade opened, a preset was created and MangoHud/Mailbox coexisted without reported issues. The user reports lower perceived latency with Mailbox than Azahar’s internal VSync. This does not validate every GPU, runner or effect; Vulkan ReShade remains labeled experimental.

Local automated validation: 911 tests, no failures, 7 skipped for unavailable tools. Additional checks covered official 32/64-bit VulkanRT DLLs, installation from 0.8.1 with and without the MangoHud test, repeated installation and offline rollback while retaining presets and MangoHud settings.

Close games and the Toolbox before updating. Both features are now available from **Tools and compatibility**; scoped test installers are no longer needed.
