# Ultimate Wine Toolbox v0.6.4

## Français

- Correction d'une seconde ouverture indésirable de la Toolbox après la fermeture de son écran de retour, notamment avec Alt+F4 sous Batocera 43.1/Xorg. Certaines versions d'EmulationStation lancent deux fois une entrée présente dans un sous-système et son groupe ; le lanceur technique ignore désormais l'exécution supplémentaire lorsque la demande de retour a déjà été consommée.
- Cette protection est commune aux retours des workflows de création et de mise à jour WSquashFS, de diagnostic ReShade et d'édition de profils AntiMicroX en jeu. L'ouverture manuelle depuis Ports reste disponible sans demande de retour.
- L'écran « Session terminée » d'AntiMicroX accuse réception du retour avant son affichage. Une fermeture du terminal ne permet plus à une demande tardive de recréer ce retour. Le profil et la session restent disponibles pour reprise manuelle, et les demandes des autres workflows sont préservées.
- Validation : suite de 555 tests automatisés, vérification GitHub et confirmation du correctif AntiMicroX sous Batocera 43.1/Xorg.

La création WSquashFS reste en bêta. Le support MangoHud des systèmes Wine custom et Wine Mono restent exclus.

## English

- Fixed an unwanted second Toolbox opening after closing its return screen, including Alt+F4 on Batocera 43.1/Xorg. Some EmulationStation versions launch an entry twice when it belongs to both a child system and its group; the technical launcher now skips the extra execution once the return request has been consumed.
- This protection is shared by WSquashFS creation and update, ReShade diagnostic and AntiMicroX in-game profile editing returns. Manual opening from Ports remains available without a return request.
- AntiMicroX's finished-session screen acknowledges the return before appearing. Closing the terminal no longer allows a late request to recreate that return. The profile and session remain available for manual recovery, and other workflows' requests are preserved.
- Validation: a suite of 555 automated tests, GitHub checks and user confirmation of the AntiMicroX fix on Batocera 43.1/Xorg.

WSquashFS creation remains in beta. MangoHud support for custom Wine systems and Wine Mono remain excluded.
