# Ultimate Wine Toolbox v0.5.8

## Français

- Gestion Wine Mono / Microsoft .NET avec diagnostic, mise à jour de Mono, remplacement par Microsoft .NET Framework 4.8 et restauration des sauvegardes.
- Installations interactives : fenêtres visibles, journaux en direct et prise en charge corrigée de TKG-v41 et GE-Proton-UMU.
- Retrait de Mono et nettoyage de ses marqueurs corrigés ; validation de .NET 4.8 fondée sur le registre et les DLL Microsoft, tolérant les seules entrées résiduelles Wine Mono Windows Support.
- Travail sur une copie du préfixe sans recopier le jeu, sauvegarde avant publication et récupération contrôlée d’une installation conservée après échec.
- Dans le workflow création, l’aide .NET est accessible après un échec de lancement ou la réponse « le jeu a planté ».
- Détection des exécutables améliorée pour les dossiers `.wine` dont le jeu est installé hors de `drive_c/game` et dont l’autorun est encore un modèle.
- Lancement de la toolbox UMU depuis l’Ultimate avec ses propres préférences de police et de fenêtre, comme depuis Ports.
- Documentation .NET intégrée en français et en anglais.

Les correctifs d’installation ont été testés avec TKG-v41 et GE-Proton-UMU. La compatibilité des jeux reste dépendante du runner et de leurs besoins .NET. Aucun contournement expérimental du message .NET au changement de runner n’est appliqué.

## English

- Wine Mono / Microsoft .NET management: inspect prefixes, update Mono, replace it with Microsoft .NET Framework 4.8, and restore backups.
- Interactive installers with visible windows, live logs, and installation fixes for TKG-v41 and GE-Proton-UMU.
- Fixed Mono removal and registry cleanup; .NET 4.8 validation checks Microsoft registry entries and DLLs while tolerating leftover Wine Mono Windows Support entries only.
- Staged prefix operations exclude game data, back up before publication, and support validated recovery of retained installations.
- Creation workflow offers .NET assistance after a failed launch or when the user reports a game crash.
- Improved executable detection for `.wine` folders with games outside `drive_c/game` and an unchanged template autorun.
- Launching UMU Toolbox from Ultimate now uses UMU’s own font and window preferences, matching its Ports entry.
- Offline .NET documentation in French and English.

Installation fixes were tested with TKG-v41 and GE-Proton-UMU. Game compatibility still depends on the runner and .NET requirements. No experimental workaround for the .NET popup when changing runners is applied.
