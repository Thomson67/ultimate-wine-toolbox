## Français

Lorsqu’un fichier Pad2Key (.keys) suspendu a été supprimé à la main, la Toolbox peut retirer l’association AntiMicroX ou supprimer le profil. Le fichier reste absent. Le Pad2Key d’origine est archivé dans `state/antimicrox-pad2key-recoveries` au cas où vous voudriez le récupérer. Si un fichier .keys modifié est encore présent, la Toolbox bloque le retrait pour protéger son contenu.

Préversion basée sur la v0.11.2. Les tests automatisés couvrent le retrait de l’association et la suppression du profil. La validation sur Batocera reste à faire.

## English

If a suspended Pad2Key (.keys) file was manually deleted, the Toolbox can remove the AntiMicroX assignment or delete the profile. The file stays absent. The original Pad2Key is archived in `state/antimicrox-pad2key-recoveries` for recovery. If an edited .keys file is still present, the Toolbox blocks removal to protect its contents.

Prerelease based on v0.11.2. Automated checks cover assignment removal and profile deletion. Batocera validation is pending.
