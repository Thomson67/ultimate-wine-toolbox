## Français

- Création et mise à jour des WSquashFS. Depuis les options du jeu testé, choisissez un bundle DXVK / VKD3D installé ou le réglage global, puis relancez le test. À la finalisation, vous pouvez appliquer le choix à l’archive produite.
- AntiMicroX. Dupliquez un profil existant pour un jeu et modifiez la copie indépendamment du profil partagé.

Préversion basée sur la v0.11.1. Les parcours WSquashFS et AntiMicroX ont été vérifiés par les tests automatisés. La validation en jeu sur Batocera reste à faire.

## English

- WSquashFS creation and updates. Choose an installed DXVK / VKD3D bundle or the global setting from the test game's options, then relaunch the test. When finalizing, you can apply the choice to the resulting archive.
- AntiMicroX. Duplicate an existing profile for a game and edit the copy independently of the shared profile.

Prerelease based on v0.11.1. Automated checks cover both workflows. In-game validation on Batocera is pending.
