## Français

Après l’installation de ReShade, choisissez **Lancer le jeu pour préparer un preset**. Cette option est aussi disponible dans le menu ReShade d’un jeu où ReShade est activé. EmulationStation lance le jeu avec son runner habituel. Appuyez sur **Home (Début)** pour régler les effets. À la fermeture du jeu, la Toolbox revient à son menu ReShade.

Préversion basée sur la v0.11.4. Le lancement et le retour ont été vérifiés en simulation. L’essai sur Batocera reste à faire.

## English

After installing ReShade, choose **Launch game to set up a preset**. The option is also available in the ReShade menu of a game where ReShade is enabled. EmulationStation starts the game with its usual runner. Press **Home** to adjust effects. When the game closes, the Toolbox returns to its ReShade menu.

Prerelease based on v0.11.4. Launch and return were verified in simulation. Testing on Batocera is pending.
