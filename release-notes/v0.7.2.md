# Ultimate Wine Toolbox v0.7.2

## Français

- **AntiMicroX en jeu sur Batocera v44 :** correction du lancement qui pouvait rester bloqué tant que l’éditeur était ouvert.
- **Hotkey+R1 :** bascule directe entre le jeu et AntiMicroX, sans double retour. La bascule attend le relâchement des boutons pour conserver les commandes en jeu, même lorsque R1 possède déjà une affectation clavier ou souris. La détection des manettes est optimisée pour limiter l’attente.
- **Alt+Tab sous labwc :** la fenêtre principale d’AntiMicroX est désormais accessible au clavier. EmulationStation est exclu du sélecteur uniquement pendant la configuration AntiMicroX ; la règle temporaire est retirée en fin de session ou lors de sa récupération.
- **Profils conservés :** ces corrections ne demandent ni de retirer les affectations de R1, ni d’activer le bureau virtuel Wine. Les raccourcis temporaires sont restaurés après la configuration.

## English

- **In-game AntiMicroX on Batocera v44:** fixed game launches that could remain blocked while the editor was open.
- **Hotkey+R1:** switches directly between the game and AntiMicroX without a double return. Switching waits for controller buttons to be released so game controls keep working, including when R1 already has a keyboard or mouse mapping. Controller discovery is optimized to reduce the delay.
- **Alt+Tab under labwc:** the AntiMicroX main window is now available to keyboard switching. EmulationStation is excluded from the switcher only during AntiMicroX configuration; the temporary rule is removed when the session ends or is recovered.
- **Existing profiles preserved:** these fixes require neither removing R1 mappings nor enabling the Wine virtual desktop. Temporary shortcuts are restored after configuration.
