## Français

- Depuis ES, l’assistant ReShade peut retrouver l’exécutable appelé par le fichier BAT de l’autorun, notamment avec START et les chemins relatifs à %~dp0.
- Un antimicrox.exe lancé depuis un autre dossier est ignoré si le batch désigne un seul autre exécutable. Les scripts ambigus proposent le choix manuel.

## English

- The ReShade installer opened from ES can find the executable launched by the autorun batch using START and paths relative to %~dp0.
- An antimicrox.exe launched from a separate directory is ignored if the batch names exactly one other executable. Ambiguous scripts keep the manual selector.
