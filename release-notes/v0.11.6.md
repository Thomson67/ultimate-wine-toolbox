## Français

- **Catalogue dans EmulationStation.** Choisissez un preset ou un pack ReShade, ou un profil AntiMicroX, dans **Options avancées du jeu → Ultimate Wine Toolbox**. Quittez le menu pour appliquer la sélection. Les deux options communautaires s’affichent indépendamment via **Paramètres → Options EmulationStation**. Les listes privilégient des libellés courts à partir des noms de fichiers.
- **ReShade.** Changez de preset déjà installé directement dans ES. Resélectionner un preset ou un pack déjà installé le réactive sans rouvrir la Toolbox. Pour une première installation, la Toolbox reprend le preset sélectionné et repère l’exécutable depuis l’autorun quand c’est possible, y compris dans les batchs simples qui lancent aussi des utilitaires externes. La détection de l’API en jeu reste disponible.
- **ReShade intégré.** **Désactivé** masque également l’injecteur d’origine si le retrait de l’installation gérée le fait réapparaître. Prend en charge les fichiers reconnus `ReShade.asi`, `ReShade32.asi` et `ReShade64.asi`. Les WSquashFS et les presets sont conservés.
- **AntiMicroX.** Un profil communautaire peut être utilisé avec le jeu sélectionné quel que soit le titre indiqué dans le catalogue. Un profil déjà téléchargé peut être associé sans rouvrir la Toolbox. L’association sauvegarde et suspend Pad2Key pour ce jeu et applique les règles launcher si le profil en contient. L’assistant reste disponible pour le premier téléchargement.
- **Retour depuis ES.** Le lanceur communautaire attend la prise en charge de la demande et bloque les relances en boucle. Certaines versions d’EmulationStation peuvent encore afficher brièvement un écran de lancement en double lorsque les Ports sont groupés.
- **Graphismes.** Ajout du modèle Batocera 44 avec DXVK 3.1.1, VKD3D-Proton 3.0.1 et DXVK-NVAPI 0.9.2.

## English

- **Catalogue in EmulationStation.** Choose a ReShade preset or bundle, or an AntiMicroX profile, in **Advanced game options → Ultimate Wine Toolbox**. Leave the menu to apply the selection. The two community options can be shown independently under **Settings → EmulationStation options**. Lists use short, filename-based labels.
- **ReShade.** Switch installed presets directly in ES. Reselect an installed preset or bundle to reactivate it without opening the Toolbox again. On first installation, the Toolbox uses the selected preset and identifies the game executable from the autorun when possible, including simple batch files that also start external utilities. In-game API detection remains available.
- **Bundled ReShade.** **Disabled** also masks the original injector if removing the managed installation exposes it again. Supports recognized `ReShade.asi`, `ReShade32.asi` and `ReShade64.asi` injectors. WSquashFS archives and presets are preserved.
- **AntiMicroX.** A community profile can be used for the selected game regardless of the title in the catalogue. Downloaded profiles can be assigned without reopening the Toolbox. Assignment backs up and suspends Pad2Key for the game and applies any launcher rules packaged with the profile. The wizard remains available for first-time downloads.
- **EmulationStation handoff.** The community launcher waits for the request to be picked up and prevents repeated launches. Some ES versions can still briefly display a duplicate launch screen when Ports are grouped.
- **Graphics.** Added the Batocera 44 model with DXVK 3.1.1, VKD3D-Proton 3.0.1 and DXVK-NVAPI 0.9.2.
