## Français

- Dans les options avancées d’EmulationStation, un profil AntiMicroX communautaire peut être associé au jeu sélectionné quel que soit le titre déclaré dans le catalogue.
- La liste affiche le nom du fichier `.amgp` avec la mention `[Launcher]` pour les configurations launcher.
- Sélectionner à nouveau le profil déjà associé évite d’ouvrir la Toolbox. Pour un partage launcher, les profils et les règles doivent déjà être en place. Une nouvelle association demande confirmation avant la suspension de Pad2Key.

## English

- In EmulationStation’s advanced game options, a community AntiMicroX profile can be assigned to the selected game regardless of the game title in the catalogue.
- The list shows the `.amgp` filename, with a `[Launcher]` suffix for launcher configurations.
- Reselecting the assigned profile keeps the Toolbox closed. Launcher bundles require the profiles and rules to already be in place. A new assignment asks for confirmation before suspending Pad2Key.
