## Français

- Souris virtuelle Windows avec activation globale ou par jeu, indépendante du clavier virtuel. Hotkey + L3 bascule le mode souris.
- Stick gauche pour le déplacement, stick droit pour la précision, A / Croix pour cliquer ou glisser, B / Rond pour Échap, X / Carré pour le clic droit, Haut / Bas pour la molette.
- Préversion cumulative. L’essai sur Batocera reste à faire, notamment avec les jeux qui lisent la manette via HIDRAW.

## English

- Windows virtual mouse with global and per-game settings, independent of the virtual keyboard. Hotkey + L3 toggles mouse mode.
- Left stick to move, right stick for precision, A / Cross to click or drag, B / Circle for Escape, X / Square to right-click, Up / Down to scroll.
- Cumulative prerelease. Batocera validation is pending, especially with games that read the controller through HIDRAW.
