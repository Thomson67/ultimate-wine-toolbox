## Français

- Depuis les options du jeu dans EmulationStation, l’assistant ReShade cible automatiquement l’exécutable déclaré dans `autorun.cmd`. S’il passe par un script ou si l’exécutable est introuvable, l’assistant propose le choix manuel.
- Un preset INI choisi dans ES est repris directement. Pour un pack ZIP, le preset initial est celui défini par le pack. Les confirmations d’installation et d’add-ons restent disponibles.
- Un diagnostic de l’API reprend l’exécutable et le partage sélectionnés, puis rend la main à EmulationStation.
- Ces raccourcis s’appliquent au parcours lancé depuis les options ES du jeu.

## English

- The ReShade installer opened from EmulationStation uses the executable declared in `autorun.cmd`. When it names a script or the executable cannot be found, the installer offers the manual choice.
- The installer uses the selected INI directly. For a ZIP pack, it uses the pack’s initial preset. Installation and add-on confirmations are preserved.
- API diagnostics retain the selected executable and preset and return to EmulationStation on completion.
- These shortcuts apply to the installer launched from a game’s ES options.
