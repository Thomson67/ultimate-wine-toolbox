# Ultimate Wine Toolbox v0.7.0

## Français

- Nouveau menu **Outils et compatibilité → Winetricks / Wine Mono / .NET**, accessible hors création d’archive, pour les jeux `.wine`, `.pc` et `.wsquashfs`.
- Catalogue Winetricks complet avec sélection multiple, descriptions et cache pour accélérer son ouverture. Les composants déjà installés sont ignorés individuellement ; les autres restent installés normalement et les erreurs sont signalées.
- Pour un WSquashFS, choix entre installation dans la bouteille du runner et **extraction → installation → recompression** pour intégrer les composants dans l’archive à partager. La copie de travail peut être reprise après une interruption ; le remplacement n’a lieu qu’après vérification complète.
- Les runners Batocera installés, dont Wine-TKG et Wine-Proton lorsqu’ils sont présents, peuvent être choisis explicitement par jeu, indépendamment du runner hérité des paramètres Wine.
- Recherche des jeux à mettre à jour améliorée : priorité au matching existant, puis suggestions plus souples pour les titres restants, classées selon les mots communs. Les titres comme « Little Nightmares III The Shores » retrouvent plus facilement « Little Nightmares III ».
- Préparation Winetricks corrigée pour les anciens liens graphiques cassés : DirectX 8 à 12, DXGI, DirectDraw, NVAPI et Optical Flow. Les remplacements disponibles sont copiés avec la bonne architecture ; les fichiers partagés du runner restent intacts. Les liens cassés vers des DLL NVAPI optionnelles absentes ne bloquent plus l’installation.
- Compression, vérification et finalisation liées à la session Toolbox : fermer sa fenêtre interrompt les tâches associées et conserve les données de reprise. Une publication déjà engagée termine sa courte transaction pour préserver la cohérence de l’archive et de son état.
- Finalisation des mises à jour désormais visible, y compris lorsqu’une sauvegarde demandée nécessite une copie complète. Le renommage final ne bascule plus silencieusement vers une copie entre disques : si le système de fichiers refuse le renommage atomique, le temporaire est conservé et l’erreur est signalée.
- Journaux enrichis avec les étapes et leurs horaires. Les rapports Winetricks sur archive sont limités aux 20 plus récents, comme les journaux de session et de vérification/MAJ.

Validation : suite de 625 tests automatisés et intégration GitHub avec montage SquashFS/OverlayFS réel ; installation de composants dans un WSquashFS extrait et présence des composants dans l’archive finale confirmées sur Batocera.

La création WSquashFS reste en bêta et la gestion Wine Mono/.NET reste expérimentale. L’arrêt des tâches ne protège pas contre une coupure électrique brutale. Le support MangoHud des systèmes Wine custom n’est pas inclus.

## English

- New **Tools and compatibility → Winetricks / Wine Mono / .NET** menu outside archive creation, supporting `.wine`, `.pc` and `.wsquashfs` games.
- Complete Winetricks catalogue with multiple selection, descriptions and caching for faster access. Already installed components are skipped individually; remaining components are still installed and failures are reported.
- WSquashFS users can choose the runner’s bottle or **extract → install → recompress** to include components in the shareable archive. Interrupted working copies can be resumed; replacement only happens after a full integrity check.
- Installed Batocera runners, including Wine-TKG and Wine-Proton when available, can be explicitly selected per game, independently of inherited Wine settings.
- Improved update matching: existing matches stay first, with broader suggestions for remaining titles ranked by shared title words. Names such as “Little Nightmares III The Shores” now find “Little Nightmares III” more easily.
- Fixed component preparation for stale graphics DLL links covering DirectX 8–12, DXGI, DirectDraw, NVAPI and Optical Flow. Available replacements are copied with architecture checks, without modifying shared runner files. Broken links to absent optional NVAPI DLLs no longer block installation.
- Compression, verification and finalization workers now follow the Toolbox session’s lifetime. Closing the window interrupts those workers and retains recovery data; a publication already in progress finishes its short transaction to keep archive and state consistent.
- Update finalization now stays visible, including a full backup copy when requested and needed. Final rename no longer silently falls back to a cross-disk copy: refused atomic renames retain the temporary archive and report failure.
- Logs now include operation phases and timestamps. Archive component reports retain only the 20 most recent files, matching session and integrity/update report retention.

Validation: a suite of 625 automated tests and GitHub integration using real SquashFS/OverlayFS mounts; component installation into an extracted WSquashFS and inclusion in the final archive confirmed on Batocera.

WSquashFS creation remains in beta and Wine Mono/.NET management remains experimental. Worker cancellation cannot protect against abrupt power loss. MangoHud support for custom Wine systems is not included.
