## Français

- L’installation retire le Port communautaire de la dev3 et active les deux nouvelles rubriques ES. Redémarrez EmulationStation et, si le Port figure encore dans la liste, actualisez les listes de jeux.
- Dans **Options avancées du jeu → Ultimate Wine Toolbox**, choisissez **Presets ReShade communautaires** ou **Profils AntiMicroX communautaires**. Le menu standard d’ES présente la liste Windows commune. Choisissez une entrée portant le nom du jeu, puis sortez avec **Retour** pour ouvrir la confirmation de téléchargement et d’application.
- Les packs ZIP ReShade et les configurations AntiMicroX multi-profils sont pris en charge. Les confirmations d’import existantes s’appliquent aussi aux add-ons ReShade.
- Le service Batocera actualise le catalogue sans ouvrir la Toolbox. ES relit les choix au redémarrage. Pour relancer une sélection annulée, validez **Auto** dans ES, puis sélectionnez de nouveau le partage.

## English

- Installation removes the separate dev3 community Port and enables both ES sections. Restart EmulationStation and refresh the game lists if the old entry still appears.
- In **Advanced Game Options → Ultimate Wine Toolbox**, choose **Community ReShade presets** or **Community AntiMicroX profiles**. Standard ES shows the shared Windows list. Select a share labelled with the game's name, then leave the menu with **Back** to open the download and apply confirmation.
- ReShade ZIP packs and complete AntiMicroX launcher configurations are supported, with the existing import confirmations for ReShade add-ons.
- The Batocera service updates the catalogue with the Toolbox closed. ES reloads choices on restart. To retry a cancelled request, save **Auto** in ES and select the share again.
