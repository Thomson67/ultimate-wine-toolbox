## Français

- **AntiMicroX**. Si le fichier Pad2Key (`.keys`) suspendu a été supprimé manuellement, la Toolbox peut retirer l’association au jeu ou supprimer le profil sans recréer le fichier. Le mapping d’origine est archivé dans `state/antimicrox-pad2key-recoveries`.
- Si un fichier `.keys` modifié est encore présent, la Toolbox bloque le retrait pour protéger son contenu.

## English

- **AntiMicroX**. If a suspended Pad2Key (`.keys`) file was manually deleted, the Toolbox can remove the game assignment or delete the profile without recreating the file. The original mapping is archived in `state/antimicrox-pad2key-recoveries`.
- If an edited `.keys` file is still present, the Toolbox blocks removal to preserve its contents.
