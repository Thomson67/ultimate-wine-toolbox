## Français

- Dans les options avancées du jeu, les partages communautaires sont placés à côté de ReShade et d’AntiMicroX. Redémarrez EmulationStation après l’installation.
- La confirmation des partages s’ouvre via le lanceur natif de la Toolbox pour que Batocera active les commandes Pad2Key de la manette.
- L’installation de ReShade depuis un preset ou un pack communautaire propose à nouveau **Détecter l’API en jeu**. Quittez le jeu pour reprendre l’installation avec la sélection communautaire conservée.
- Pour réessayer le même partage que dans la dev4, validez d’abord **Auto** avec **Retour**, puis sélectionnez de nouveau le partage.

## English

- In Advanced Game Options, community shares appear next to ReShade and AntiMicroX. Restart EmulationStation after installation.
- The confirmation window opens through the native Toolbox launcher so Batocera enables the controller’s Pad2Key mapping.
- ReShade installation from a community preset or pack offers **Detect API in game** again. Exit the game to resume installation with the same community selection.
- To retry the same share used in dev4, save **Auto** with **Back**, then select the share again.
