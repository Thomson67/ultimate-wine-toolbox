# Ultimate Wine Toolbox v0.6.3

## Français

- Correction des sélecteurs graphiques avec les versions récentes de YAD, notamment sous Batocera v44 : recherche des sauvegardes, choix de la source de mise à jour, profils AntiMicroX/Pad2Key et import/export ReShade. L'option utilisée reste compatible avec les anciennes versions de YAD.
- Ajout de l'inspection en lecture seule des sauvegardes existantes dans le workflow de mise à jour WSquashFS, y compris les anciens liens personnalisés. Un lien vers la racine partagée propose les sous-dossiers à consulter sans ouvrir toute la racine.
- Correction du bouton Retour entre le choix final de l'archive et les sauvegardes, ainsi que du retour vers l'étape de test depuis la révision des sauvegardes, y compris pour une mise à jour déjà en attente.
- Reprise des tests avec les sauvegardes de travail isolées et restauration des règles de sauvegarde d'origine lors de leur conservation. Les anciens liens vers la racine partagée conservent leur politique d'origine.
- Validation automatisée et essais sous Batocera v44. La création WSquashFS reste en bêta.

Le support MangoHud des systèmes Wine custom et l'intégration Wine Mono ne font pas partie de cette release. Les correctifs des runners UMU sont publiés séparément dans UMU Runner Toolbox v0.13.11.

## English

- Fixed graphical file pickers with recent YAD versions, including Batocera v44: save browsing, update source selection, AntiMicroX/Pad2Key profiles and ReShade import/export. The supported option remains compatible with older YAD versions.
- Added read-only inspection of existing saves in the WSquashFS update workflow, including legacy custom links. Links to the shared save root offer individual child directories without browsing the whole root.
- Fixed Back navigation from the final archive choice to save review and from save review to game testing, including updates already pending when the Toolbox is upgraded.
- Retests restore isolated working saves, and keeping existing saves restores their original rules. Legacy links to the shared save root retain their existing policy.
- Automated validation and Batocera v44 testing. WSquashFS creation remains in beta.

MangoHud support for custom Wine systems and Wine Mono integration are not included. UMU runner fixes are released separately in UMU Runner Toolbox v0.13.11.
