## Français

- Dans **Paramètres → Options EmulationStation**, cochez **Bundle DXVK / VKD3D**, puis redémarrez EmulationStation. Le menu **Ultimate Wine Toolbox** des options avancées Windows ou du jeu propose les bundles installés et les **Versions natives de Batocera**.
- **Auto** suit les réglages existants. Priorité : ES par jeu, Toolbox par jeu, ES Windows, Toolbox globale. Un bundle choisi pour un test WSquashFS reste prioritaire.
- La Toolbox actualise la liste après installation ou suppression d’un bundle. Redémarrez ES pour l’afficher. Les bundles affectés dans ES sont protégés contre la suppression depuis la Toolbox. Si un bundle manque au lancement, la Toolbox passe au réglage suivant.
- Préversion cumulative. Le choix et la restauration du bundle sont vérifiés par des tests automatisés. L’essai dans le menu de Batocera reste à faire.

## English

- In **Settings → EmulationStation options**, select **DXVK / VKD3D bundle** and restart ES. The **Ultimate Wine Toolbox** submenu of the advanced Windows and game options shows installed bundles and **Batocera defaults**.
- **Auto** follows existing settings. Priority: ES per game, Toolbox per game, ES Windows, global Toolbox. A WSquashFS test bundle still takes priority.
- Installing or deleting a bundle refreshes the list. Restart ES to display it. Bundles assigned in ES are protected from removal through the Toolbox. When an assigned bundle is missing at launch, the next setting takes effect.
- Cumulative prerelease. Automated tests cover selection and restoration. Batocera menu validation is pending.
