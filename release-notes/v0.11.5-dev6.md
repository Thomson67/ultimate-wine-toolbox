## Français

Dans **Paramètres → Options EmulationStation**, cochez les rubriques à afficher. Redémarrez EmulationStation, puis ouvrez **Ultimate Wine Toolbox** dans les options avancées Windows ou celles d’un jeu. Les cases choisissent les rubriques visibles. Sélectionnez les valeurs dans ES pour les appliquer.

- **MangoHud** propose l’activation, le profil, la limite FPS et le mode de présentation Vulkan.
- **AntiMicroX** permet d’utiliser ou de suspendre le profil déjà associé. **Clavier virtuel** et **Souris virtuelle** se règlent séparément.
- **ReShade** peut être activé ou désactivé dans ES pour un jeu déjà configuré dans la Toolbox.
- **Réafficher le launcher** se règle par jeu. La Toolbox lit le batch choisi par autorun.cmd et utilise la destination de copy /y NUL si elle correspond au IF EXIST. Seul conf-ok.txt est mis de côté dans les sauvegardes externes. Le marqueur d’origine est restauré si le batch ne le recrée pas. Les WSquashFS sont lus avec unsquashfs -cat. Si ES affiche encore l’ancienne valeur après usage, enregistrez **Démarrage normal**, puis réactivez **Au prochain démarrage**.

Pour MangoHud et les entrées virtuelles, l’ordre est **ES par jeu → Toolbox par jeu → ES Windows → Toolbox globale**. AntiMicroX conserve son profil associé et applique l’interrupteur ES du jeu, puis celui du système. ReShade et le launcher utilisent les valeurs ES par jeu. Un réglage ES masqué par la liste à cocher cesse de s’appliquer. Le menu compte sur le chargement des fichiers additionnels es_features_*.cfg par EmulationStation.

Préversion cumulative. L’affichage du menu et le lancement réel restent à vérifier sur Batocera.

## English

Open **Settings → EmulationStation options** and tick the sections to expose, then restart EmulationStation. The **Ultimate Wine Toolbox** submenu appears under advanced Windows or game options. Select values in ES to apply them.

- **MangoHud** includes enable/disable, display profile, FPS limit and Vulkan presentation mode.
- **AntiMicroX** can use or suspend an existing profile assignment. **Virtual keyboard** and **Virtual mouse** have separate settings.
- **ReShade** can be enabled or disabled in ES for games already configured in the Toolbox.
- **Show the launcher again** works per game. The Toolbox reads the batch selected by autorun.cmd and checks that the copy /y NUL and IF EXIST paths agree. It temporarily moves conf-ok.txt in external saves and restores the original marker if the batch does not recreate it. WSquashFS files are read with unsquashfs -cat. If ES still shows the old choice after use, save **Normal launch** before choosing **On next launch** again.

For MangoHud and virtual input, priority is **ES game → Toolbox game → ES Windows → Toolbox global**. AntiMicroX keeps the existing assigned profile and uses the ES game or system switch. ReShade and launcher reset read per-game ES settings. Hidden sections stop applying their ES overrides. EmulationStation must support additional es_features_*.cfg files.

Cumulative prerelease. In-game and menu validation on Batocera is pending.
