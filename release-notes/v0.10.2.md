# Ultimate Wine Toolbox v0.10.2

## Français

- **Retour dans la Toolbox fiabilisé** après un test de jeu : le lanceur de retour déjà enregistré dans EmulationStation est réutilisé sans recharger inutilement toute la collection.
- Une actualisation reste prévue si le lanceur est absent, modifié ou doit être réparé.
- **Pas de demande en double** lorsque la Toolbox est déjà en cours de démarrage. Si un autre jeu est lancé, aucune nouvelle tentative de retour ne vient l’interrompre.
- Journal enrichi avec les durées, les réponses HTTP et les changements d’état d’ES pour faciliter le diagnostic.

Le regroupement de Ports, les statistiques ES et les commandes manette sont conservés. Le correctif utilise le mécanisme de retour commun aux workflows WSquashFS, AntiMicroX et ReShade.

Validation utilisateur : plusieurs tests et retours Toolbox effectués sans nouvelle occurrence du problème signalé. Les tests automatisés couvrent notamment la réutilisation du lanceur, les actualisations nécessaires, la conservation des statistiques et l’absence de lancement en double.

Fermer les jeux et la Toolbox avant la mise à jour.

## English

- **More reliable returns to the Toolbox** after game tests: reuse the return launcher already indexed by EmulationStation without unnecessarily reloading the whole collection.
- Refresh the index when the launcher is missing, changed or requires repair.
- **No duplicate request** while the Toolbox launcher is already starting. If another game starts, further return attempts do not interrupt it.
- More detailed timings, HTTP responses and ES state changes in the return log for troubleshooting.

Ports grouping, ES statistics and controller input are preserved. This change uses the return mechanism shared by WSquashFS, AntiMicroX and ReShade workflows.

User validation: several game tests and Toolbox returns without recurrence of the reported problem. Automated tests cover launcher reuse, necessary refreshes, retained statistics and duplicate-launch prevention.

Close games and the Toolbox before updating.
