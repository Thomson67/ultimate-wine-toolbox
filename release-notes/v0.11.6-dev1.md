## Français

- Le gestionnaire DXVK / VKD3D propose le modèle **Batocera 44** sous **Installer un modèle Batocera**. Basé sur la branche RC, il utilise DXVK 2.7.1, VKD3D-Proton 3.0a et DXVK-NVAPI 0.9.0, comme le modèle 43 / 43.1.
- Après installation, le bundle est disponible dans la Toolbox et dans les options avancées d’EmulationStation si la rubrique DXVK / VKD3D est activée. Redémarrez EmulationStation pour rafraîchir la liste.

## English

- The DXVK / VKD3D manager offers a **Batocera 44** model under **Install a Batocera model**. It follows the RC branch and uses DXVK 2.7.1, VKD3D-Proton 3.0a and DXVK-NVAPI 0.9.0, the same versions as the 43 / 43.1 model.
- Once installed, the bundle is available in the Toolbox and in EmulationStation's advanced options when the DXVK / VKD3D section is enabled. Restart EmulationStation to refresh the list.
