# Ultimate Wine Toolbox v0.8.1

## Français

Correctif des liens de sauvegarde pendant les mises à jour WSquashFS.

- Si les nouveaux fichiers contiennent déjà des liens aux emplacements de sauvegarde connus, la Toolbox propose de les remplacer par ceux de la configuration existante. Les anciens dossiers cibles restent conservés.
- Une configuration existante contenant des liens vers un ancien dossier temporaire `.uwt-test-…` est désormais refusée avant le déplacement des fichiers du jeu. Elle ne peut plus être republiée en conservant ces mauvaises destinations.
- Le contrôle s’applique aussi aux anciennes opérations en attente, avant compression, même si la vérification d’intégrité est ignorée.
- Les copies de sauvegarde restent disponibles pour récupération. Comparer leurs progressions et réparer les destinations permanentes avant de relancer une opération bloquée : aucune copie n’est choisie automatiquement.

Validation automatisée : 886 tests, aucun échec, 7 ignorés dans l’environnement de test. Huit nouveaux tests couvrent notamment le cas des liens mixtes de Dying Light 2, les cibles absentes, la reprise et la conservation des liens permanents après suppression des backups. Pas de nouvelle validation sur matériel Batocera pour ce correctif.

Fermer le jeu et la Toolbox avant la mise à jour. Cette version ne répare pas automatiquement les archives déjà affectées.

## English

Save-link fixes for WSquashFS updates.

- When new game files already contain links at known save locations, the Toolbox offers to replace them with the existing configuration’s links. Previous target directories are retained.
- Existing configurations pointing to an old `.uwt-test-…` directory are now refused before game files are moved, preventing publication with stale destinations.
- Pending operations are also checked before compression, even when archive integrity verification is skipped.
- Save copies remain available for recovery. Compare progress and repair permanent destinations before retrying a blocked operation; no save copy is selected automatically.

Automated validation: 886 tests, no failures, 7 skipped in the test environment. Eight new regressions cover mixed Dying Light 2 links, missing targets, resume and permanent-link preservation after backup cleanup. No new Batocera hardware validation was performed for this patch.

Close the game and Toolbox before updating. This version does not automatically repair already affected archives.
