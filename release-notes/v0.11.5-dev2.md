## Français

- Création et mise à jour WSquashFS : affichez le chemin de l’exécutable actuel ou sélectionnez manuellement un fichier .exe, .bat ou .cmd avec Yad. La liste des exécutables détectés reste disponible.
- Cette préversion inclut aussi le lancement du jeu pour préparer un preset ReShade, introduit dans la v0.11.5-dev1.

## English

- WSquashFS creation and update: view the current executable path or select an .exe, .bat, or .cmd file manually with Yad. The list of detected executables remains available.
- This prerelease also includes the in-game ReShade preset setup introduced in v0.11.5-dev1.
