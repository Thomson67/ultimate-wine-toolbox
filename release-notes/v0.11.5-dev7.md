## Français

- **Afficher le launcher (par jeu) → Oui** ouvre le launcher à chaque démarrage. **Non** rend la main au démarrage normal du jeu. La Toolbox met temporairement de côté conf-ok.txt et restaure le marqueur d’origine si le batch ne le recrée pas.
- **ReShade → Désactivé** dans ES masque aussi les DLL ReShade standard déjà intégrées au jeu. Les presets restent disponibles et les DLL sont restaurées à la sortie. Les chargeurs personnalisés non reconnus restent hors de portée.
- Après la mise à jour, redémarrez EmulationStation pour afficher le nouveau menu. Si vous avez déjà utilisé l’ancienne option ponctuelle, sélectionnez **Oui** pour l’activer à nouveau.

## English

- **Show launcher (per game) → Yes** opens the launcher on every start. **No** returns to the game's normal launch behavior. The Toolbox temporarily moves conf-ok.txt and restores the original marker if the batch does not recreate it.
- **ReShade → Disabled** in ES also temporarily masks recognized ReShade injector DLLs bundled with the game. Presets are preserved and the DLLs are restored when the game exits. Unrecognized custom loaders are not changed.
- After updating, restart EmulationStation to refresh the menu. If you already used the former one-shot setting, choose **Yes** to enable it again.
