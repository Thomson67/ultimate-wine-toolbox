## Français

- **WSquashFS**. En création et en mise à jour, ouvrez les options du jeu testé pour choisir un bundle DXVK / VKD3D installé ou suivre le réglage global, puis relancez le test. En mise à jour, le premier essai reprend le bundle associé à l’archive. À la finalisation, vous pouvez conserver le réglage testé pour le WSquashFS, même si vous le renommez.
- **AntiMicroX**. Dupliquez un profil existant pour le jeu de votre choix. Vous pouvez modifier la copie indépendamment du profil partagé.

## English

- **WSquashFS**. During creation and updates, select an installed DXVK / VKD3D bundle or follow the global setting in the test game's options, then relaunch the test. The first update test uses the archive's assigned bundle. When finalizing, you can save the tested setting for the resulting WSquashFS, even if you rename it.
- **AntiMicroX**. Duplicate an existing profile for the game of your choice. You can edit the copy independently of the shared profile.
