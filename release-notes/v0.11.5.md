## Français

### Options EmulationStation

Dans **Paramètres → Options EmulationStation**, cochez les réglages à afficher. Redémarrez EmulationStation, puis ouvrez **Ultimate Wine Toolbox** dans les options avancées Windows ou celles du jeu.

- **DXVK / VKD3D** propose les bundles installés et les versions natives de Batocera. **Auto** suit les réglages existants. L’ordre de priorité est ES par jeu, Toolbox par jeu, ES Windows, puis Toolbox globale. Le bundle choisi pour un test WSquashFS garde la priorité. Redémarrez ES après une modification de la liste des bundles. La Toolbox protège les bundles utilisés dans ES contre la suppression.
- **MangoHud** permet de régler l’activation, le profil, la limite de FPS et le mode de présentation Vulkan, dont Mailbox. **AntiMicroX** permet d’utiliser ou de suspendre le profil déjà associé. Le clavier et la souris virtuels se règlent séparément.
- **Afficher le launcher → Oui** ouvre le launcher à chaque démarrage des jeux compatibles. **Non** rétablit le comportement normal. La Toolbox se fonde sur le chemin de `conf-ok.txt` déclaré dans le batch et remet le marqueur d’origine en place si le jeu ne le recrée pas.
- **ReShade → Désactivé** masque aussi les injecteurs ReShade reconnus qui sont intégrés au jeu ou au préfixe, y compris dans un WSquashFS. Les presets sont conservés.

### Souris virtuelle et workflows

- **Hotkey + L3** bascule la souris virtuelle indépendamment du clavier. Stick gauche pour déplacer le pointeur, stick droit pour les mouvements précis, A / Croix pour cliquer ou glisser, B / Rond pour Échap, X / Carré pour le clic droit et Haut / Bas pour la molette. Un rappel s’affiche en haut à droite et laisse passer les clics. Le raccourci natif « Disque suivant » de Batocera ne bloque plus la bascule dans les jeux Windows.
- Après l’installation de **ReShade**, lancez directement le jeu pour préparer un preset.
- En **création et mise à jour WSquashFS**, affichez le chemin de l’exécutable actuel ou choisissez un fichier `.exe`, `.bat` ou `.cmd` manuellement avec Yad. La liste des exécutables détectés reste disponible.

## English

### EmulationStation options

In **Settings → EmulationStation options**, select the settings to expose. Restart EmulationStation, then open **Ultimate Wine Toolbox** in the advanced Windows or game options.

- **DXVK / VKD3D** offers installed bundles and Batocera defaults. **Auto** follows the existing settings. Priority runs from ES per game to Toolbox per game, ES Windows, then global Toolbox. A WSquashFS test bundle takes precedence. Restart ES after changes to the installed bundle list. The Toolbox protects bundles assigned in ES from removal.
- **MangoHud** includes an enable switch, display profile, FPS limit and Vulkan presentation mode, including Mailbox. **AntiMicroX** can use or suspend the assigned profile. Virtual keyboard and mouse have separate settings.
- **Show launcher → Yes** displays the launcher every time a compatible game starts. **No** restores normal launch behavior. The Toolbox uses the `conf-ok.txt` path declared in the batch file and restores the original marker if the game does not recreate it.
- **ReShade → Disabled** also masks recognized ReShade injectors bundled with a game or prefix, including WSquashFS archives. Presets are preserved.

### Virtual mouse and workflows

- **Hotkey + L3** toggles the virtual mouse independently of the keyboard. Left stick moves the pointer, right stick makes finer movements, A / Cross clicks or drags, B / Circle sends Escape, X / Square right-clicks and Up / Down scrolls. A click-through indicator in the upper-right corner lists the bindings. Batocera’s stock next-disc shortcut no longer blocks mouse mode in Windows games.
- Launch the game straight after installing **ReShade** to set up a preset.
- When **creating or updating a WSquashFS**, view the current executable path or manually select an `.exe`, `.bat` or `.cmd` with Yad. The detected executable list is still available.
