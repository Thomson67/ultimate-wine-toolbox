# Ultimate Wine Toolbox v0.8.0

## Français

### AntiMicroX : launchers et jeux

- **Bascule automatique des profils selon la fenêtre** : commandes du launcher uniquement, ou profils distincts pour le launcher et le jeu. Les règles utilisent le titre, la classe ou l’exécutable et peuvent distinguer deux fenêtres du même processus, ou une fenêtre dont le titre change.
- **Configuration et retest intégrés** : relevé des fenêtres en jeu, choix des règles, puis retest sans rouvrir l’éditeur. Les fenêtres sont classées par première observation. Les règles ciblent les fenêtres Wine Xorg/XWayland ; le pilote Wine Wayland natif n’est pas couvert.
- **Édition séparée des deux profils**, en jeu ou sans lancer le jeu. L’édition du profil jeu conserve l’association du launcher et ses règles.
- **Menus regroupés** pour modifier les fenêtres, les profils associés, partager/exporter ou désactiver/supprimer une configuration. Les profils encore utilisés ailleurs restent protégés ; un menu séparé permet de nettoyer les profils sans jeu associé.

### Partage et transfert des configurations

- **Partage communautaire complet** : profils launcher/jeu et règles de fenêtres sont transmis ensemble, sans chemins locaux ni identifiants de manette. Les anciens profils simples restent compatibles.
- **Export ZIP d’un ou plusieurs jeux**, sans formulaire de nom, pseudo ou description. Les listes proposent uniquement les jeux disposant d’un profil et repèrent les configurations launcher.
- **Réimport sur une autre machine ou un autre format de jeu** : choisir le jeu cible réassocie les profils et règles. Le parcours `.wine` → partage communautaire → réimport pour le même jeu en `.wsquashfs` a été validé sur la machine Batocera v44 de test.

### MAJ WSquashFS et documentation

- **Choix de conserver ou supprimer les backups de sauvegardes créés par la MAJ**, après réussite de la publication. Les sauvegardes actives, l’éventuel backup du WSquashFS et les backups de MAJ précédentes restent protégés. Une copie modifiée est conservée pour vérification.
- Menus et intitulés longs plus faciles à consulter, avec accès au texte complet sans déclencher l’action.
- Documentation et aides intégrées **français/anglais actualisées** : launchers, transferts, suppressions, sauvegardes, Winetricks et limites de compatibilité. Les guides détaillés sont également inclus dans l’archive de release.

Les profils et configurations créés pendant les tests sont conservés lors de la mise à jour normale. Fermer le jeu, AntiMicroX et la Toolbox avant l’installation.

## English

### AntiMicroX: launchers and games

- **Automatic window-based profile switching**: launcher-only controls or separate launcher and game profiles. Rules match titles, classes or executables, including two windows from one process or one window whose title changes.
- **Integrated setup and retesting**: record windows in game, select rules and retest without reopening the editor. Windows follow first-observed order. Rules support Wine Xorg/XWayland windows, not the native Wine Wayland driver.
- **Edit each role separately**, in game or without launching it. Editing the game profile preserves the launcher assignment and rules.
- **Grouped management menus** for windows, assigned profiles, sharing/export and disabling/deleting configurations. Referenced profiles stay protected; a separate list cleans profiles without an assigned game.

### Configuration sharing and transfer

- **Complete community sharing** includes both role profiles and window rules, without local paths or controller identities. Existing simple profiles remain compatible.
- **Export one or several games to a ZIP** without a game-name, nickname or description form. Pickers only show games with an available profile and identify launcher configurations.
- **Import on another machine or for another game format**: select the target game to restore its profiles and rules. The `.wine` → community share → import for the same `.wsquashfs` game workflow was validated on the Batocera v44 test machine.

### WSquashFS updates and documentation

- **Choose whether to keep or remove save-data backups created by the update**, after successful publication. Active saves, any WSquashFS backup and backups from earlier updates remain protected. Modified copies are retained for review.
- Easier access to long menu entries, including full text without activating an action.
- Updated **French/English offline help and documentation** for launchers, transfers, deletion, saves, Winetricks and compatibility limits. Detailed guides are also included in the release archive.

Profiles and configurations created during testing are retained by the normal update. Close the game, AntiMicroX and the Toolbox before installation.
