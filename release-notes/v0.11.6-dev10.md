## Français

- Depuis les options ES, l’installation ReShade peut retrouver l’exécutable dans le batch déclaré par l’autorun. Elle reconnaît les appels directs, les formes simples de START et les chemins relatifs à %~dp0.
- La Toolbox lit le script dans le jeu ou dans l’archive WSquashFS et vérifie l’exécutable sélectionné. Un batch dynamique ou ambigu déclenche le choix manuel.

## English

- ReShade installation from ES can find the executable in the batch file specified by autorun. It understands direct calls, simple START commands, and %~dp0 paths.
- The Toolbox reads the script from the game or WSquashFS archive and validates the executable. Dynamic or ambiguous scripts fall back to the manual selector.
