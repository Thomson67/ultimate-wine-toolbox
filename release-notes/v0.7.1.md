# Ultimate Wine Toolbox v0.7.1

## Français

- **AntiMicroX :** les jeux `.wine` et `.pc` présents sur les disques sont désormais proposés pour l’affectation d’un profil existant, même s’ils ne sont pas renvoyés par EmulationStation. Les copies de travail cachées sont exclues des sélecteurs de jeux, notamment pour ReShade, MangoHud et DXVK.
- **Espace disque avec mergerfs :** avant compression, la Toolbox examine chaque branche autorisée en écriture et choisit celle offrant le plus d’espace utilisable, avec un contrôle prudent de la place nécessaire. Cela concerne la création, les mises à jour et la recompression après installation de composants. Les capacités relevées et le disque choisi sont indiqués dans le journal.
- **Reprise d’une MAJ :** la finalisation reste possible si l’archive originale a été supprimée après préparation. La nouvelle archive est créée sans tenter de sauvegarder l’ancienne ; un fichier réapparu entre-temps n’est pas écrasé.
- **Nettoyage final :** la suppression du `.wine` est visible, liée à la session Toolbox et terminée avant le message de réussite. Les erreurs sont affichées et journalisées. Pour une MAJ déjà publiée, le nettoyage interrompu peut être repris sans recompresser l’archive.
- **Squashage simple :** le bilan attend la publication de l’archive et le nettoyage demandé. Les nettoyages incomplets sont comptabilisés séparément ; un échec de publication affiche le journal correspondant.
- **Rapports d’erreur :** les sorties de compression et de publication figurent dans le rapport annoncé à l’écran, avec le code de retour et la durée. Les erreurs d’espace disque et de renommage sont ainsi directement accessibles.

## English

- **AntiMicroX:** local `.wine` and `.pc` games are now available when assigning an existing profile, even when EmulationStation does not return them. Hidden working copies are excluded from game pickers, including ReShade, MangoHud and DXVK.
- **mergerfs disk space:** before compression, the Toolbox examines writable branches and selects the one with the most usable free space, using a conservative space check. This covers creation, updates and recompression after component installation. Per-branch capacities and the selected disk are recorded in the log.
- **Update recovery:** finalization can proceed if the original archive was deleted after preparation. The replacement is created without attempting to back up the missing original; a file appearing at that path in the meantime is not overwritten.
- **Final cleanup:** source `.wine` removal stays visible, follows the Toolbox session and finishes before the success message. Errors are displayed and logged. An interrupted cleanup for an already published update can be resumed without recompressing the archive.
- **Simple squash:** the summary waits for archive publication and requested cleanup. Incomplete cleanups are counted separately, and publication failures display the corresponding report.
- **Error reports:** compression and publication output now appears in the report shown on screen, including exit status and duration. Disk-space and rename errors are directly accessible.
