## Français

- Le modèle **Batocera 44** correspond au changelog et aux recettes de compilation de Batocera v44. Il installe **DXVK 3.1.1**, **VKD3D-Proton 3.0.1** et **DXVK-NVAPI 0.9.2**.
- Depuis la dev1, installez à nouveau le modèle **Batocera 44** puis sélectionnez le nouveau bundle. Son nom contient les trois versions corrigées.
- Les versions des modèles 40, 41, 42, 43 et 43.1 ont été vérifiées avec leurs tags officiels.

## English

- The **Batocera 44** model matches the Batocera v44 changelog and build recipes. It installs **DXVK 3.1.1**, **VKD3D-Proton 3.0.1** and **DXVK-NVAPI 0.9.2**.
- When upgrading from dev1, install the **Batocera 44** model again and select the new bundle. Its name includes the three corrected versions.
- The 40, 41, 42, 43 and 43.1 model versions were verified against their official tags.
