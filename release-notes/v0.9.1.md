# Ultimate Wine Toolbox v0.9.1

## Français

- Correction de la création d’un WSquashFS lorsque l’extraction du modèle de préfixe échoue avec « Too many open files ». La limite de fichiers ouverts est relevée dans le sous-processus d’extraction et le modèle est extrait avec un seul processus. La compression du jeu conserve ses réglages.
- La sortie de préparation est enregistrée dans le journal de session. En cas d’échec, le message affiche désormais le chemin du journal et le détail technique, en français comme en anglais.

Validation matérielle : correctif d’extraction testé avec succès par l’utilisateur sur Batocera, pour Stranger of Paradise Final Fantasy Origin, avec le modèle par défaut et un pool mergerfs.

Validation automatisée ciblée : limite héritée basse, conservation de la limite du processus parent, préparation des fichiers visibles et cachés, préservation du jeu source après échec d’extraction, et affichage du diagnostic avec le chemin du journal. Contrôle syntaxique de tous les scripts shell.

## English

- Fix WSquashFS creation when prefix template extraction fails with “Too many open files”. Raise the open-file limit only in the extraction subprocess and extract the template with one worker. Game compression settings are unchanged.
- Capture preparation output in the session log. Preparation failures now show the log path and technical details in both languages.

Hardware validation: the user successfully tested the extraction fix on Batocera with Stranger of Paradise Final Fantasy Origin, the default prefix template and a mergerfs pool.

Targeted automated validation: low inherited limit, unchanged parent process limit, visible/hidden game file preparation, source preservation after extraction failure, and error/log-path display. All shell scripts pass syntax checks.
